# Поиск любимых фильмов

Приложение на Python, PyQt5 и SQLite. Поиск фильмов по названию, жанру, году и длительности, список избранного и рекомендации по годам и жанрам понравившихся фильмов.

## Запуск

Нужен Python 3.12. Команды выполняются из папки проекта.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python main.py
```

В PyCharm используется интерпретатор `.venv/bin/python` и конфигурация `FilmSearch` из `.run/`.

## Файлы

- `main.py` — окна и работа с базами.
- `films_db.sqlite` — каталог: 17 184 фильма и 22 жанра.
- `films_love.sqlite` — избранное.
- `films_result.sqlite` — результаты поиска.
- `films_recomendations.sqlite` — рекомендации.
- `img.png` — изображение главного окна.
- `docs/` — презентация, пояснительная записка и первоначальная конфигурация сборки.

Базы и изображение открываются относительно `main.py`, поэтому текущая папка терминала на их поиск не влияет. Избранное сохраняется между запусками. При заполненном названии поиск выполняется по точному названию; остальные поля в этом случае не учитываются.

## Проверки

```bash
python -m unittest -v
```

Проверки используют временные копии баз. Каталог и сохранённое избранное не изменяются.

Проект начат в 2022 году. В рабочей версии исправлены поиск по году и длительности, повторное добавление в избранное и обновление таблиц. Проверяется запуск из исходников; файл сборки 2022 года в `docs/` сохранён отдельно.
